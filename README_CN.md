# BirdPilot（鸟哨）

[English](README.md) | [中文](README_CN.md)

BirdPilot 是一个面向鸟类自动识别的边缘 AI 项目，覆盖从数据训练、模型导出到设备端推理的完整流程。

项目不只想训练一个分类模型，而是要做出一套可以运行在嵌入式设备上的鸟类智能观测原型。

```
摄像头
  ↓
鸟类画面
  ↓
物种识别
  ↓
本地记录
```

目标部署平台：**RK3588 边缘设备**。

## 项目目标

BirdPilot 目前围绕三件事推进：

1. 鸟类物种分类模型训练；
2. 模型导出与推理验证；
3. 边缘设备部署与自动观测。

项目重点是工程可复现和部署准备，而不是提出新的神经网络结构。

## 数据集

使用数据集：**Birds-525 Species Dataset**。

| 划分 | 图片数量 |
|---|---:|
| 训练集 | 约 8.4 万 |
| 验证集 | 约 2,600 |
| 测试集 | 约 2,600 |

- 鸟种类别数：524；
- 图片大小：224 × 224 RGB；
- 本地目录：`data/birds`，其中包含 `train`、`valid`、`test` 和 `birds.csv`。

图片通常是一张图中只有一只鸟，且鸟占主要位置。

## 模型

### ResNet18

作为稳定的基线模型，优点是训练成熟、表现可靠。

### MobileNetV3

作为当前优先部署的轻量模型，参数更少、推理更快，更适合边缘设备。

## 实验进展

### exp001：小规模试跑（Mac）

用很小的数据子集确认数据读取和训练脚本能正常工作。

### exp002：扩大子集训练

用更大的子集观察训练过程；训练损失下降，验证准确率提高。

### exp003：云端烟雾测试

在云端 GPU 上进行短训练，确认 CUDA 环境、数据读取和训练脚本可用。

### exp004：ResNet18 全量训练

硬件：NVIDIA RTX 5090。

| 指标 | 结果 |
|---|---:|
| 最佳验证准确率 | 97.94% |
| 测试准确率 | 99.20% |

### exp005：MobileNetV3 轻量模型评估

硬件：NVIDIA RTX 5090。

| 指标 | 结果 |
|---|---:|
| 最佳验证准确率 | 98.63% |
| 测试准确率 | 99.24% |

MobileNetV3 在验证集上略高，同时明显更轻，因此作为当前主要部署候选。

### exp006：ONNX 导出与运行验证

已完成 PyTorch checkpoint 到 ONNX 的导出，并在同一张图片上确认 PyTorch 与 ONNX 的预测一致。

### exp007：真实图片 ONNX 基准

测试图片：`data/birds/test/ABYSSINIAN GROUND HORNBILL/1.jpg`。

| 环节 | 平均耗时 |
|---|---:|
| 图片读取 | 0.500 ms |
| 预处理 | 0.495 ms |
| 模型推理 | 5.680 ms |
| 后处理 | 0.015 ms |
| 总耗时 | 6.690 ms |

约为 149 FPS。该数据来自 Mac CPU + ONNX Runtime，本身不是 RK3588S 板端数据。

## 模型对比

| 模型 | 参数量 | 验证准确率 | 测试准确率 | 部署优先级 |
|---|---:|---:|---:|---|
| ResNet18 | 约 1,100 万 | 97.94% | 99.20% | 次要 |
| MobileNetV3 | 约 540 万 | 98.63% | 99.24% | 主要 |

MobileNetV3 是当前准确率与计算开销之间更合适的平衡点。

## 当前阶段

已完成：三随机种子的成对鲁棒性训练、锁定测试集评估、ONNX 导出、FP16 RKNN 转换和真实 RK3588S 部署。

2026-09-21，增强模型在复用测试集上的干净准确率为 99.20%，15 个固定退化条件均值为 98.50%。其 FP16 RKNN 在真实 QuarkPi-CA2 上与 ONNX 完成 20/20 top-1 对齐；单图 30 次 NPU 推理中位延迟为 22.69 ms，P95 为 29.98 ms。完整结果和证据边界见 [exp014 结果](experiments/exp014_robustness_finetune_results.md)。

当前边界仍是摄像头。exp016 已把正式检测候选冻结为 Apache-2.0 的 YOLOX-Nano：54 张外部鸟图检出 `44/54`，检出场景裁剪分类 `33/44`，漏检计失败时端到端 `33/54`，20 张 empty 图零触发。Toolkit2 2.0.0 FP16 RKNN 已生成，本地模拟器在 94 张代理图上保持门控、最高分框和裁剪分类 top-1 一致，匹配框最低 IoU 为 0.9668。详情与证据边界见 [exp016 固定机位视角代理集](experiments/exp016_fixed_view_proxy_plan.md)。这些仍是外部代理数据，不替代真实板端、摄像头或户外验收。

两位成员当前的协作方式见 [TEAM_ONBOARDING.md](TEAM_ONBOARDING.md)。

## 长期目标

BirdPilot 希望形成一套轻量、可部署的鸟类自动观测系统，结合计算机视觉、边缘 AI 与嵌入式系统。
